## 📋 Visão Geral

Este projeto calcula a quantidade de materiais necessários para a execução de alvenaria, auxiliando na estimativa de blocos, argamassa e outros insumos relacionados.

---

## 🎯 Objetivo

Automatizar o cálculo de materiais para alvenaria utilizando Python, fornecendo estimativas rápidas e confiáveis para auxiliar estudantes, profissionais da construção civil e desenvolvedores interessados em aplicar programação na solução de problemas reais da engenharia.

---

## ✨ Funcionalidades

- Calcular a área da parede
- Estimar a quantidade de blocos
- Estimar o consumo de argamassa
- Interface simples via terminal
